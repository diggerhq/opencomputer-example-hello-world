# OpenComputer Hello World

A minimal serverless agent for the OpenComputer **From scratch** quick start.

[Deploy with OpenComputer](https://app.opencomputer.dev/new?repository-url=https%3A%2F%2Fgithub.com%2Fdiggerhq%2Fopencomputer-example-hello-world)

To run it locally:

```bash
npm install
npx --package @opencomputer/cli opencomputer login
npm run deploy -- --watch
```
